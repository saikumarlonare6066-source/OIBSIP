# Student Performance Analysis

# Project Overview

This project analyzes student academic performance using Python. It studies subject-wise marks, student averages, and the relationship between daily study hours and average marks.

# Objectives

- Calculate average marks in Maths, Science, and English.
- Identify the highest student average.
- Compare student performance across subjects.
- Explore the relationship between study hours and average marks.
- Visualize the results using graphs.

# Technologies Used

- Python
- Pandas
- Matplotlib

# Dataset

The project uses a sample dataset containing 20 students, their gender, daily study hours, attendance, and marks in three subjects.

# Visualizations

1. Average Marks by Subject
2. Student-wise Average Marks
3. Study Hours vs Average Marks

# How to Run

1. Install the required libraries:
   "pip install pandas matplotlib"
2. Open the project folder in VS Code.
3. Run:
   "py student_performance_analysis.py"

# Output

The analysis results are displayed in the terminal. Three graphs are saved in the "outputs" folder.
