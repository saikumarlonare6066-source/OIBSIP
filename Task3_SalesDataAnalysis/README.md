Sales Data Analysis using Python

Project Overview

This project analyzes sales data using Python to understand revenue, product performance, and city-wise sales.

Objectives

- Calculate total sales revenue.
- Analyze revenue by product.
- Compare sales across different cities.
- Identify monthly sales trends.
- Visualize sales data using graphs.

Technologies Used

- Python
- Pandas
- Matplotlib
- VS Code

Dataset

The project uses "sales_data.csv", which contains order ID, order date, product, category, quantity, unit price, and city.

Analysis Performed

- Total revenue calculation
- Total quantity sold
- Product-wise revenue analysis
- City-wise revenue analysis
- Monthly sales trend visualization

Output Graphs

The generated graphs are saved in the "outputs" folder:

- "monthly_sales_trend.png"
- "revenue_by_product.png"
- "revenue_by_city.png"

How to Run

1. Install the required libraries:
   py -m pip install pandas matplotlib
2. Run the Python program:
   py sales_data_analysis.py

Conclusion

This project demonstrates how Python can be used to analyze sales data and create visualizations to understand business performance.
