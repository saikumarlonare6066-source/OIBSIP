
# Retail Sales Data Analysis

## Project Overview
This project analyzes retail sales data using Python.
The main goal is to understand sales trends, product
performance, and country-wise revenue.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- VS Code

## Tasks Performed
1. Data loading and exploration
2. Data cleaning
3. Descriptive statistics
4. Revenue calculation
5. Monthly sales trend analysis
6. Top 10 products by revenue
7. Top 10 countries by revenue
8. Correlation heatmap
9. Business insights and recommendations

## Output Files
- top_10_products.png
- top_10_countries.png
- correlation_heatmap.png

## Conclusion
This project helps identify sales trends,
high-revenue products, and important markets
to support better business decisions.
